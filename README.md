# Tarea 1 - CRUD en PostgreSQL con Python

Aplicación de consola para la gestión de alumnos utilizando Python puro y la librería `psycopg2`.

## Requisitos
- Python 3.x
- PostgreSQL
- Librería `psycopg2` 

## Ejecución
1. Crear la base de datos `tarea1` en PostgreSQL.
2. Configurar las credenciales en `main.py`.
3. Ejecutar con: `python main.py`
